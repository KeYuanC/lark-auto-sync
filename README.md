# Lark Auto Sync

[简体中文](README.zh-CN.md) | [English](README.en.md)

Profile-driven, safety-first synchronization of approved Feishu/Lark chat
attachments to local destinations and GitHub. It supports Markdown conversion,
bounded Codex extraction, deterministic routing, Feishu receipts, and Windows or
macOS background services.
